# Governance

**Maintainer:** Ahmed Zaki (project owner). This repository contains the independently published community source, not the official production operations repository.

## Decisions and review

The maintainer sets project scope and release readiness, decides whether issues and pull requests are accepted, reviews code and documentation, and appoints future maintainers if necessary. Discussion is welcome; publishing a feature request, donation or pull request does not guarantee acceptance or a release date.

Contributions must pass privacy/security/license review and the finalized non-exclusive contributor agreement **before merge**. The current agreement is only a draft; external contribution intake remains closed until a verifiable signing/check process is activated. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Branches and releases

`main` is the published community source. Changes should be developed and tested on isolated branches, reviewed in pull requests, and merged only after checks pass. Stable tags and signed installers require additional [release gates](docs/RELEASING.md). Public source releases do not automatically deploy the separately hosted service.

## Transparency

Maintain accurate [project status](docs/PROJECT_STATUS.md), [roadmap](docs/ROADMAP.md) and [changelog](CHANGELOG.md); distinguish tested behavior from proposed features and disclose relevant security limitations. Please use issues for non-sensitive proposals and [private security reporting](SECURITY.md) for vulnerabilities.
