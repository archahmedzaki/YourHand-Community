# Security

Do not file public issues containing account identifiers, enrollment keys, OAuth tokens, private certificates, recovery codes, database copies, screenshots or customer information. Remove secrets from diagnostics before sharing; rotate exposed credentials. This source-only candidate is not approved as a drop-in replacement for existing production deployments.

Windows privilege elevation requires explicit local administrator approval. Do not attempt to capture, control or bypass protected UAC/Winlogon desktops. Test the Agent only on devices you own or are authorized to control.
