# Community Code of Conduct

YourHand welcomes respectful technical discussion, reproducible bug reports and good-faith security feedback from people of all backgrounds.

**Expected behavior:** be professional; discuss code and evidence rather than attacking people; respect consent, device ownership and privacy; avoid posting credentials or customer data; give constructive review feedback.

**Not acceptable:** harassment, discriminatory insults, threats, stalking, nonconsensual access to devices, publication of private information, social engineering for credentials, spam or deliberate disruption of other contributors' work.

Maintainers may hide or remove content, close threads, restrict participation or escalate serious incidents to the relevant service provider. Moderation decisions should consider context and safety; participation does not create an entitlement to merge access.

For ordinary conduct questions, use a sanitized GitHub issue or repository discussion. For threats, doxxing, security vulnerabilities or private customer data, **do not post details publicly**; use [the private security reporting route](SECURITY.md). An independent reporting channel is a maintenance item until the owner configures it.
